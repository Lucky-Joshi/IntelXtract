# Example Reports

This directory contains sample output reports generated by IntelXtract for documentation and reference purposes.

All targets are sanitized/public domains (example.com) and safe for distribution.

|------|-------------|

| `scan-example-com-quick.html` | Quick scan of example.com (HTML) |
| `scan-example-com-deep.json` | Deep scan of example.com (JSON) |
| `scan-example-com-deep.html` | Deep scan of example.com (HTML) |
| `scan-example-com-deep.md` | Deep scan of example.com (Markdown) |
| `scan-example-com-deep.csv` | Deep scan of example.com (CSV) |

## Generating Your Own Reports

```bash
# Quick scan + HTML report
intelxtract scan example.com --mode quick
intelxtract report <scan-id> --format html --out report.html

# Deep scan + multiple formats
intelxtract scan example.com --mode deep
intelxtract report <scan-id> --format json --out report.json
intelxtract report <scan-id> --format html --out report.html
intelxtract report <scan-id> --format md --out report.md
intelxtract report <scan-id> --format csv --out report.csv
intelxtract report <scan-id> --format pdf --out report.pdf  # requires WeasyPrint

# Case report (multiple scans)
intelxtract case create "Investigation Name"
intelxtract case attach <case-id> --scan <scan-id-1>
intelxtract case attach <case-id> --scan <scan-id-2>
intelxtract case export <case-id> --format html --out case-report.html
```

## Report Formats

| Format | Extension | Use Case |
|--------|-----------|----------|
| JSON | `.json` | Machine processing, API integration |
| HTML | `.html` | Human-readable, styled, printable |
| PDF | `.pdf` | Formal reports, offline sharing (requires WeasyPrint) |
| Markdown | `.md` | Documentation, GitHub rendering |
| CSV | `.csv` | Spreadsheet analysis, data export |

## Sanitization

All example reports use `example.com` (IANA reserved domain) as the target.
No private data, internal IPs, or sensitive findings are included.
